# 토큰·비용·결과물 대조 및 모델 선정 — 0.2

정리일: 2026-10-20 (한국 시간). 공개 단가 확인일: 2026-10-19.

## 결정

기본 모델을 **gpt-6-luna**로 변경했다. 이번 가상 평가에서 주요 기준을 충족한 후보 중 요청당 추정 비용이 가장 낮았다. 모든 업무·모든 모델에 대한 보편적인 최적 모델이라는 뜻은 아니다.

기존 0.1의 gpt-4.1-mini와 비교해 평균 입력 토큰은 **34.9%**, 평균 요청 비용 추정치는 **83.2%** 감소했다. 단가 변경 효과와 전송 방식 효과가 함께 포함된 수치다. 같은 gpt-4.1-mini로 전송 방식만 개선했을 때는 입력 **40.2%**, 비용 **43.4%** 감소했다. 최적화 후 결과 분량·품질도 달라지므로 완전히 동일한 출력의 압축률은 아니다.

## 시험 조건

- 실제 사용자 예시 기업 자료는 전송하지 않았다. 명확한 가상 PDF·회의록 3종: 일반 텍스트 3쪽, 수치 상충 8쪽, 그림에만 정보가 있는 혼합 문서 4쪽.
- 초기 비교 36회 + 안내 처리 규칙 개선 후 최종 비교 60회 = **실제 API 96회**. 연결 확인·별도 앱 통합 시험은 이 횟수와 합계 비용에서 제외했다.
- 최종 비교는 모델별 3자료 × 2반복 × 초안/수정 2단계 = 12회. 모든 후보는 동일한 최종 지시문·자료·수정 요청을 받았다. 초안은 각 모델이 작성했으므로 수정 입력의 초안 부분은 모델별로 다르다.
- 2개 작업을 동시에 실행하고 순서를 섞었다. 새 모델은 reasoning=none. 요청당 제한은 최대 6,000토큰부터 시작하며 긴 직접 편집 초안은 최대 24,000까지 늘린다. 실제 사용량은 API usage를 기록했다.
- 서비스 별칭 모델을 사용했으므로 향후 서버 모델 변경 시 결과가 달라질 수 있다. 2반복의 소규모 가상 시험이며 실제 업무 품질·속도의 통계적 보장은 아니다.

GPT-6 luna의 자동 실패 1건은 ‘기업 설명에 따르면 센서 9대를 설치했고…’를 정규식이 놓친 경우다. 실제 결과는 기업 설명과 점검자 확인을 구분하므로 이 항목은 원문 대조 후 통과로 기록했다. 원래 자동판정은 수정하지 않고 원자료에 남겼다. 최종 12개 결과에서 요청한 계획 구역·직접 확인·수정 문장을 확인했다. 수치 상충 설명의 문장이 다소 어색하거나 확인 사항을 반복하는 경우가 있어 사람의 최종 검수는 필요하다.

GPT-4.1 mini는 요청한 계획 구역 정보를 자주 누락했고, GPT-5.4 mini는 일부 수정에서 결과서 대신 수정 설명을 작성했다. 5.6 luna·terra도 주요 기준은 통과했으나 비용이 더 높았다. 자동판정의 표현 오판 때문에 모델 순위를 점수 한 개로 정하지 않았다.

## 경량화 내용과 정보 보존

1. PDF 전체와 앞쪽 추출 텍스트를 동시에 보내던 중복을 제거했다. 일반 텍스트 쪽은 전체 추출 텍스트로 보내고, 그림·도형·주석·회전·추출 불확실 쪽은 원본 PDF 페이지로 보낸다. 모든 쪽을 둘 중 하나로 포함하고 원본 쪽 번호를 표시한다.
2. AI 요약으로 원본을 압축하지 않는다. 페이지를 임의로 자르지 않으며, 한도 초과 시 오류로 안내한다. 이미지 속 고유 구역명이 실제 생성 결과에 유지되는 것을 확인했다.
3. 일반현황 인용 확인 범위를 앞 8쪽에서 모든 쪽으로 확대했다. 스캔 이미지에서만 읽히는 값은 로컬 정확 인용을 확인할 수 없어 자동 입력하지 않고 사용자에게 확인받는다.
4. 이미 입력된 일반현황의 근거 3항목을 반복 생성하지 않는다. 채팅 수정에서는 일반현황을 재생성하지 않고 사용자가 입력한 값을 유지한다. 원본 자료와 현재 직접 편집한 초안은 매번 함께 전달한다.
5. 출력의 불필요한 반복과 마크다운 장식을 줄였다. 안내와 조치요청은 구분한다. 상충 정보는 확인할 사항으로 분리한다.
6. 추가 추론 토큰을 사용하지 않는 설정으로 이번 결과를 검증했다. 앱에 입력/출력 토큰과 해당 요청의 USD 비용 추정치를 표시한다. 업무내용·키·초안을 로그 파일로 저장하지 않는다.

PDF의 복잡한 다단 편집·특수 글꼴·숨은 정보 등은 추출 결과가 다를 수 있다. 시각 요소가 있거나 추출이 불확실한 페이지는 PDF로 보존하지만 모든 종류의 PDF 추출 정확도를 보장하지 않는다. 스캔·도표가 많은 문서는 텍스트 문서보다 절감 폭이 작을 수 있다.

## 단가와 해석

API usage의 input/output/cached/cache_write/reasoning 토큰과 실제 결과 전문은 별도 CSV·JSON으로 제공한다. 캐시 적중·쓰기 과금 및 해당 모델의 긴 문맥 단가를 계산에 반영했다. 실제 청구서가 아닌 공개 단가 기준 USD 추정치이며 세금·환율·계약별 가격은 제외했다. 캐시 적중은 실행 환경에 따라 달라진다.

이번 96회 비교의 추정 합계는 **$0.3919**다. 앱 연결 확인과 최종 통합 시험은 추가 소량 사용분이며 이 합계에 포함되지 않는다.
