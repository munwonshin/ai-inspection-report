# 0.4.9 앱 내부 달력

방문일자 입력창을 누르면 채팅 입력창 바로 위에 달력 카드가 펼쳐진다. 날짜를 한 번 클릭하면 YYYY-MM-DD로 반영되고 즉시 접힌다. 별도 운영체제 창/제목표시줄/작업표시줄 항목을 만들지 않는다. 달력 밖 클릭과 Escape로 변경 없이 닫을 수 있고, 직접 날짜 입력과 Alt+↓도 유지한다. 승인 누락값 창의 달력도 해당 창 안에서 펼쳐지도록 변경했다.

방문기관·점검자 소속·점검자의 사용자별 고정 저장, API 키의 Windows 보안 저장소 보관, 승인 전 결과 저장 차단은 동일하다. API 모델·프롬프트·출력·파일명·HWP 모듈은 변경하지 않았다.

## 검증 범위

실제 Tk에서 1320×880/1060×720 및 기본/큰 글꼴 네 조합으로, 별도 Toplevel 창이 추가되지 않음·채팅 입력 바로 위 배치·6주 달력의 영역 유지·윤년 날짜 한 번 클릭 반영을 검사한다. 달력/고정값 시나리오 7개, 전체 단위검사 67개, 기본 화면 배치 24개도 확인한다. 검증 결과가 모두 통과한 배포본만 제공한다.

이번 변경에서 실제 OpenAI 호출·실물 NAS·한글 메뉴 재열기·화면 캡처 육안 검수는 수행하지 않는다. HWP 모듈은 직전 0.4.8과 바이트 동일함을 확인하며 당시 실제 저장/한글 재입력 결과는 CALENDAR_PIN_VERIFICATION.md에 분리되어 있다.


2026-10-23 결과: 위 네 가지 실제 Tk 조합의 새 창 없음/배치/6주 달/날짜 한 번 클릭 검사 통과, 달력·고정 시나리오 7개 통과, 전체 단위 67개 및 화면 배치 24개 통과. API/HWP 모듈은 0.4.8과 바이트 동일 여부를 배포 직전 검사한다.
