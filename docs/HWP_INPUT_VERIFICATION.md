# 0.4.16 HWP 사업계획서 첨부 검증

검증일: 2026-11-02. Windows 11·한글 2018 환경, 명확한 가상 문서만 사용했습니다.

## 변경

- PDF/HWP 1개를 파일 선택 또는 드래그 앤 드롭으로 첨부합니다. HWP 5 형식의 .hwp를 지원하며 .hwpx는 이번 범위에 포함하지 않습니다.
- HWP 원본은 읽기 전용으로 취급하고, 별도 한글 COM 작업에서 메모리로 읽어 임시 PDF로 변환합니다. 원본에 저장하지 않습니다.
- 표·그림을 포함한 변환 PDF 전체를 일반현황 분석에 전달합니다. 기존 전체 페이지 보존 방식으로 초안·채팅 수정에도 연결합니다. AI 작성 근거의 우선순위는 바꾸지 않았습니다.
- 입력 변환용 PDF는 사용자 결과 저장 경로가 아닌 로컬 임시 폴더에서 처리하며 정상·오류 경로에서 정리합니다. 비정상 종료에 따른 잔여 파일까지 없음을 보장하지 않습니다.
- 입력은 30MB·1~250쪽으로 제한합니다. 형식 위장·초과 크기·쪽수 불일치를 거부합니다. 작업 시간 초과 또는 한글 설치/보호/손상 문제는 원인을 안내하고 기존 첨부·회의록·편집 초안을 유지합니다.
- HWP 첨부에 한글 자동화가 필요하며 다른 PC에서는 파일 접근 확인이 표시될 수 있습니다. 보안 설정을 해제하지 않습니다.

## 실제 검증

- 98개 단위검사 통과: 기존 90개와 HWP 형식·크기·변환 오류·시간 초과·임시 파일 정리·원본 보존·쪽수 검사·기존 PDF 준비 연결 8개.
- 실제 Windows TkDND: 한글·공백·중괄호·대문자 확장자 경로, 파일 선택/드롭, 바쁜 상태 차단, 변환 실패 시 기존 문서/입력 보존, × 해제·재첨부, HWPX/다중 파일 거부 통과. 변환·API·저장은 이 GUI 회귀 검사에서 모의 처리했습니다.
- 기존 PDF 첨부·삭제·재첨부 회귀 검사 통과.
- 실제 한글에서 가상 HWP를 읽어 전체 2쪽 PDF로 변환하고 1,786자의 로컬 텍스트를 확인했습니다. 원본 해시는 동일했습니다. 한 번의 변환·읽기는 약 27.9초였으며 성능 보장 수치가 아닙니다.
- 실제 Tk 앱에서 가상 HWP 첨부 → 일반현황 자동 인식 → 실제 AI 초안 → 직접 검수 메모 삽입 → 실제 채팅 수정 → 승인 → 진짜 HWP 저장·한글 재입력 검증 통과. 승인 직전 결과 폴더가 비어 있음을 확인했고 직접 편집 문장과 원본 파일을 보존했습니다.
- HWP 관련 실제 AI 시험은 일반현황·초안·수정의 별도 시험이며, 이전 버전의 22회 수정 시험 건수에 합산하지 않습니다.
- 최종 배포 EXE의 16개 모듈이 소스와 일치함을 확인했습니다. EXE의 HWP 작업 모듈로 가상 HWP를 전체 2쪽 PDF(100,477바이트)로 변환했고 원본 해시를 보존했습니다. 같은 EXE의 실제 API 연결과 인증서·호스트 이름 검증도 통과했습니다.
- 초기 배포 시험에서는 변환 시간이 초과됐습니다. 변환 전용 한글 창을 표시하고 업무 내용 없는 임시 단계 진단을 추가한 뒤 최종 EXE를 재빌드·재시험했습니다. 최종 변환은 완료됐지만 모든 환경에서 확인 창이 없거나 제한 시간 내 완료됨을 보장하지는 않습니다.

## 한계

암호·DRM/보호·손상·외부 개체·특수 글꼴이 있는 모든 HWP의 변환 품질을 검증하지 않았습니다. 변환된 쪽수·자동 입력값·생성 본문은 검수해야 합니다. 다른 PC·한글 버전·실제 NAS는 이번에 추가 검증하지 않았습니다. 입력 변환용 임시 PDF와 승인 후 생성하는 결과 HWP는 서로 다른 단계입니다.
