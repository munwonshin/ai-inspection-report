# C1 전용 시험 환경 — 공개용 체크리스트

2026-11-13 추가: 기존 설치 Windows11·한글2018 환경의 독립 합성 폴더에서 지정 실제 COM 검증을 완료했다. 기존 한글이 없는지 확인하고 새 HWND/PID 소유 관계를 확인했다. 전용 VM/계정은 생성하지 않았으며, 기존 사용자 세션 공존·다중 버전·상용 안정성은 아직 별도 범위다. **한글 파일 접근 보안 승인은 사용자가 직접 수행한다. 호출 시간에는 승인 대기가 포함되므로 순수 처리시간으로 쓰지 않는다.** [최종 범위](QUALITY_REVIEW.md).

아래는 환경 확장 시 사용할 준비 체크리스트이며, 모든 상용 조건을 완료했다는 의미가 아니다.


2026-11-12 기준. 내부 환경 계획에서 사용자·호스트 식별 경로를 제외한 요약이다. 체크리스트 설계는 완료했으나 VM/계정 생성·실제 COM 활성화·HWP 저장은 수행하지 않았다. 실제 실행에는 환경과 정확한 경로를 정한 별도 승인이 필요하다.

## 환경 준비

- [ ] 전용 Windows VM 우선 검토. 독립 계정은 OS·서비스를 공유하므로 VM과 동등한 격리로 보지 않는다.
- [ ] 업무 문서·API 키·NAS 자격증명·호스트 업무 폴더 공유를 제외한다.
- [ ] 한글 설치 매체·라이선스·버전·실행 파일·서명, Python 실행 파일·비트수·패키지 버전을 확인한다.
- [ ] 시험 계정 관점의 ProgID/CLSID·서버 등록과 32/64비트 보기를 읽기 점검한다. 등록 존재를 활성화 성공으로 해석하지 않는다.
- [ ] 기준 Python 3.12.14·pywin32 312와 실제 환경 차이를 기록한다. 비트수 일치만으로 COM 호환을 보장하지 않는다.
- [ ] 외부 통신을 UI·worker·감시자 범위에서 차단한다. 자동 API/설정 복원을 비활성화한다.
- [ ] `<TEST_ROOT>/inputs`, `outputs`, `evidence`, `runtime-temp`의 실제 로컬 경로·접근 권한·junction/공유 연결을 확인하고 승인받는다.

`<TEST_ROOT>`는 환경 독립적인 설명용 자리표시자다. 실행 가능한 절대 경로가 아니며 호스트의 기존 합성 폴더를 게스트 출력 경로로 가정하지 않는다. 준비·설치·등록 변경도 현재 승인된 작업이 아니다.

## 프로세스 격리

- [ ] 시작 전 PID·생성 시각·소유 계정·Session ID·실행 파일의 경로/해시를 기록한다. 다른 사용자의 문서명은 수집하지 않는다.
- [ ] 실제 COM 승인 후 최소 객체 생성 단계에서 객체/창과 새 한글 PID의 대응을 확인한다.
- [ ] 단순히 새 PID이거나 Python 자식이라는 이유만으로 소유권을 판단하지 않는다. 대응이 불명확하면 저장·Clear·Quit를 진행하지 않는다.
- [ ] 기존 사용자 세션·기존 한글·소유 불명 프로세스를 종료하지 않는다. 이름/트리 기반 일괄 종료 금지.

현재 DispatchEx 사용만으로 기존 세션 격리를 증명하지 못한다. 객체와 PID 대응 확인 도구·절차는 설계 상태이며 검증 완료가 아니다.

## 외부 감시·중단

COM 호출 worker와 별도 프로세스에서 생존·경과시간·승인 폴더 변화를 관찰하는 방안을 설계했다. 2초 관측·60초 경고는 제안값이며 자동 timeout 구현이 아니다. 60초 무진전 시 다음 시험/중복 저장을 중단하고 시각·PID 신원·파일 목록·대화 문구를 기록한다.

보안 대화 자동 허용, 전체 한글 종료, UI 잠금 우회, 자동 재시도는 하지 않는다. 강제 종료·잔여물 삭제·VM 복원은 증거 보존 후 별도 승인받는다. worker 종료만으로 한글 종료나 뒤늦은 파일 게시 중단을 보장하지 않는다. 자동 정리로 임시 파일을 확보하지 못하면 미확보로 기록한다.

## 시험 전후 확인

- [ ] 입력 7개·소스·의존성·양식 해시와 프로세스 시작 목록을 기록한다.
- [ ] 새 출력 4개·보호 사본·증거 경로의 충돌이 없다. 기존 파일을 지워 준비하지 않는다.
- [ ] 정상 저장·최종 파일 재열기·정답 일치·B 변경 차단/재검토·파일명 변경·동명 거절·장문 60문단을 개별 판정한다.
- [ ] 입력/양식 해시 불변, A/보호 사본/보존 확인 파일의 동명 시도 전후 해시 불변을 확인한다.
- [ ] 내용·자동 서식·모든 페이지 시각 검수를 분리한다. HWP 재열기 전후 해시도 확인한다.
- [ ] worker/한글 종료와 잔여 임시 파일을 각각 확인한다. 수동 삭제·재저장으로 실패 증거를 없애지 않는다.
