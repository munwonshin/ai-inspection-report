# C1 자료 변경 후 재검수 PRD — 공개본

2026-11-13 현행화. 원본 PRD의 문제·범위·수용 계약을 공개 가능한 형태로 정리했다. 원본과 원시 증거는 변경하지 않았다. **C1 개발·정의된 E2E·품질 검증 완료.** 작업 브랜치에서 검토하며 main의 프로그램 코드는 v0.4.26으로 유지한다. 배포 EXE·상용 환경 안정성·정식 출시는 별도 미검증/승인 대기다.

## 문제 정의와 사용자 가치

자료를 변경해도 이전 보고서 본문이 남아 있어, 재검토 없이 잘못된 내용을 승인할 수 있었다. 본문 보존은 편집 손실을 막는 데 필요하므로 자료 변경 때 무조건 지우는 대신 **작성 내용은 유지하고 재검토를 요구하며, 검토 전에는 저장을 차단**한다.

대상 사용자는 현장점검 결과서를 작성·검수하는 실무자다. 실제 혼재 발생 빈도·피해 규모는 미측정이다. 문제 근거는 기존 코드의 승인 경계와 합성 기준선이며 사용자 인터뷰나 운영 사고 통계가 아니다.

## 개선 목표와 측정

| 목표 | 지표 정의 | 고정 합성 기준 | 실제 결과 |
| --- | --- | --- | --- |
| 미검토 확정 방지 | 미검토인데 저장 함수에 도달한 승인 시도 / 유효 미검토 시도 | 0/18 | 18/18→0/18 |
| 정상 흐름 보존 | 정상인데 저장 함수에 도달하지 못한 시도 / 유효 정상 시도 | 0/30 유지 | 0/30 유지 |
| 승인 내용 일치 | 검토한 내용과 전달한 Report, 정상 호출 횟수 | 내용 일치·각 1회 | 고정 합성 계약 통과 |

16개 시나리오(U6/N10)를 3회씩 실행한 48회다. API·HWP 저장은 대역을 사용했고 관측 경계는 실제 UI의 승인→저장 함수 호출이다. 실제 HWP 생성 성공률·운영 사고 감소율이 아니다. 활성 검수시간은 지표 정의만 있으며 미측정이다.

## MVP와 제외 범위

| MVP 범위 | 사용자에게 보이는 동작 |
| --- | --- |
| 자료 식별 | 같은 경로라도 처리한 자료 내용이 달라지면 새 자료로 구분 |
| 변경 표시 | 기존 본문을 보존하면서 재검수가 필요한 이유 표시 |
| 명시 검토 | 현재 자료·본문·일반현황·문서 제목을 대조한 뒤 검토 완료 확인 |
| 복원·비동기 일치 | 과거 초안·늦은 AI 응답이 이전 검토를 되살리거나 최신 입력을 덮어쓰지 않음 |
| 승인 전 보호 | 현재 내용의 검토가 유효할 때만 기존 승인 저장 경로로 전달 |

수정 차이 화면(C3), 저장 timeout·재시도·복구(C2), 자동 사실 판정, 새 파서·모델, 자동저장·원격 계측은 추가하지 않는다.

## 핵심 요구사항

- 첨부는 성공한 준비 결과의 실제 처리 내용을 비교한다. 파일 경로만으로 같다고 판단하지 않는다. HWP 처리 패킷의 식별값을 원본 파일 해시라고 부르지 않는다.
- 동일 처리 자료 재첨부와 회의록의 줄바꿈 형식(CRLF/CR/LF)만 변경한 경우는 검토를 유지한다. 글자·숫자·공백 변경은 재검수한다.
- 본문·일반현황·문서 제목의 연도/분과 변경은 검토를 무효화한다. 저장 파일명·폴더만 변경하면 내용 검토를 유지한다.
- 수동 작성도 가능하며 명시 검토 후 기존 필수값·경로·중복·양식 검사를 거친다. 검토 확인만으로 파일을 저장하지 않는다.
- 부분 수정 성공·거절·오류가 자료 변경으로 생긴 재검수를 해제하지 않는다. 복원은 같은 내용이어도 다시 검토한다.
- A→B→A·초기화 이후에도 과거 요청을 현재 요청으로 인정하지 않는다. 현재 자료와 일치하는 전체 생성만 현재 초안으로 연결한다.
- 첨부 실패/취소/미지원은 기존 자료·본문·검토를 보존한다. 초기화는 성공할 때만 작업을 비우고 API 설정을 유지한다.
- 상태·식별값은 메모리에서 다루며 신규 API·키 접근·업무 원문 로그·원격 전송을 추가하지 않는다. 로드 후 외부 파일 변경은 재첨부 전 자동 감시하지 않는다.

## AC01~AC14 수용 기준

각 승인 사례는 의도한 누락 시험 외에는 필수값·연도·분과·저장 설정을 갖춰 C1 이외의 검사에 우연히 막히지 않게 준비한다. PASS-S는 합성 범위의 통과다.

X8은 부분 수정·지연 응답·검토 취소/변경·필수값 보완·초기화·복원/불명·동일성·저장 경계의 분기 그룹이며 M01/M02의 18/30 분모에 합산하지 않는다. 현재 수용 26/26·GUI QA 4/4·기존 단위 151/151 통과다. 과거 오프라인 147+설치 COM 4 제외는 이전 이력이며 최종 네이티브 검사에서는 제외하지 않았다. 추가 1개는 재저장 실패 표시 회귀다.
