# C1 출시 검토 — 공개용 요약

2026-11-12 기준. 내부 실행 승인안의 정확한 호스트 경로를 제외한 공개용 요약이다. 실제 COM 실행·경로 사용·릴리스 승인을 대신하지 않는다. 내부 원본은 로컬에 보존하고 Git 추가 대상에서 제외한다.

## 결정

**C1 로컬 구현·합성 결과는 승인, 실제 HWP COM 시험은 전용 환경 준비 전까지 보류. 정식 출시·메인 병합도 보류한다.**

| 완료한 검증 | 결과 | 범위 |
| --- | --- | --- |
| 동일 합성 시나리오 16개×3회 | 48회 통과 | 실제 UI→저장 함수 호출. API/HWP 저장은 대역 |
| 미검토 저장 진입 | 18/18→0/18 | 운영 혼재율 아님 |
| 정상 저장 오차단 | 0/30 유지 | 실제 HWP 저장 성공률 아님 |
| 신규 수용 검사 | 25개 통과 | 상태/식별 9개와 UI 메서드 16개 |
| 기존 GUI QA | 4/4 통과 | workflow 필수 연도·분과 fixture는 별도 정비 |
| 기존 단위 검사 | 147/151 통과·4개 제외 | Windows 설치 COM 4개 제외, HWP 저장소 대역 사용 |
| 수용 기준 | AC01~AC13 합성 통과, AC14 모의만 완료 | X01~X07 합성, X08 실제 HWP 부분 미실행 |

[검증 집계](EVIDENCE_SUMMARY.md)와 [PRD](PM_CASE_STUDY.md#4-prd와-14개-수용-기준)를 함께 읽는다. 제외한 4개는 한글 저장 검사가 아니라 바로가기 설치/재설치/실패 정리/기존 링크 보존 검사다. 이전 151개 통과와 이번 147+4는 실행 조건이 다르다.

## 미검증과 출시 게이트

- 실제 HWP 생성·최종 파일 재열기·내용/서식 일치·기존 파일 보호
- 전용 Windows/한글 환경, COM 객체와 시험 PID의 소유 관계, 외부 감시/중단 절차
- native 저장소 및 설치 COM·배포 EXE 검증
- C1 실사용 검수시간·안내 이해·운영 혼재 빈도·만족도

합성 통과를 위 항목의 완료로 확대하지 않는다. 과거 버전의 실제 한글 연동 기록도 C1 결과로 대체하지 않는다. [환경 준비](TEST_ENVIRONMENT_PUBLIC.md)

## 실제 시험의 계획 범위 — 아직 실행하지 않음

향후 승인받을 전용 로컬 시험 루트를 `<TEST_ROOT>`로 표기한다. 이는 실제 경로가 아닌 설명용 자리표시자이며 실행 전에 절대 경로를 비공개 승인안에서 확정해야 한다.

| 논리 경로 | 계획 |
| --- | --- |
| `<TEST_ROOT>/inputs/` | 합성 A/B PDF·회의록·정답 7개, 읽기 전용 |
| `<TEST_ROOT>/outputs/` | C1_A.hwp·C1_B.hwp·C1_RENAMED.hwp·C1_LONG.hwp를 새로 생성할 계획 |
| `<TEST_ROOT>/evidence/` | C1_A.before.hwp 보호 사본·해시·환경·수동 검수 증거 |
| `<TEST_ROOT>/runtime-temp/` | 해당 실행의 임시 작업 파일만 허용할 계획 |

시험 순서는 정상 저장→최종 재열기/내용 비교→자료 변경 후 미검토 차단→B 명시 검토·저장→파일명 변경→동명 저장 거절/기존 파일 해시 확인→60문단 장문 서식→사후 점검이다. 명시 검토와 최종 저장 승인은 별도 단계다.

기존 파일 보호 시험은 새로 만든 합성 A 파일에 대해 덮어쓰기가 거절되는지 확인하는 것이다. 실사용 파일 변경, 기존 한글 창 조작, NAS, 외부 API, 레지스트리·보안 변경, 일괄 프로세스 종료는 포함하지 않는다. 강제 종료·잔여 파일 수동 삭제·재시험·추가 경로는 별도 승인 대상이다. 현재 저장 코드에는 timeout이 없으므로 전용 환경과 감시 준비 없이 실행하지 않는다.
