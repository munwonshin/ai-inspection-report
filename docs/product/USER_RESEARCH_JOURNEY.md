# 사용자 리서치와 여정 지도 — C1 공개본

> **상태:** 기존 업무 경험과 소스·합성 시험을 근거로 작성한 **분석/조사 설계 문서**. C1 관련 정식 인터뷰·사용성 테스트는 **미수행**이며 아래 여정의 감정·빈도·소요시간은 관측치가 아니다.

## 1. 사용자와 근거 수준

| 구분 | 확인한 사실 | 해석 한계 |
| --- | --- | --- |
| 핵심 사용자 | 현장점검 결과서를 작성·검수하는 실무자(작성자 본인의 업무) | 별도 사용자 세그먼트 규모 조사 없음 |
| 초기 실제 사용 | 본인 업무 3건 이상에 자동화 도구 적용, 작성시간 약 60분→3분 | 자기 측정, 원시 건별 로그·대조군 없음. C1 효과 아님 |
| 실제 동료 의견 | 날짜 입력이 불편하다는 피드백을 기존 제품의 달력 기능에 반영 | C1 재검수 개선에 대한 인터뷰 증거 아님 |
| C1 문제 근거 | v0.4.26 소스의 승인 경계 및 개인정보 없는 A/B 합성 재현 | 실제 기업 내용 혼재 사고·발생률 미측정 |

## 2. 사용자 여정 지도 (합성 위험 시나리오, 실제 조사 결과 아님)

| 단계 | 사용자 목표·행동 | 기존 흐름의 위험 | C1에서 기대하는 대응 | 확인할 질문 |
| --- | --- | --- | --- | --- |
| 자료 준비 | A 사업계획서·회의록 첨부 | 다른 자료와 구분하는 검수 절차 부족 | 처리한 자료를 현재 작업과 연결 | 자료의 출처를 구분하는가? |
| 초안 작성 | AI 초안 생성 후 내용 편집 | 작성 내용 손실은 피해야 함 | 편집된 본문 유지 | 어떤 부분을 수정하는가? |
| 자료 교체 | A에서 B 사업계획서·회의록 변경 | A 본문과 B 자료가 동시에 남음 | 본문 보존·재검수 필요 안내 | 안내를 즉시 인지하는가? |
| 승인 시도 | 저장 버튼 클릭 | 대조하지 않은 이전 본문이 저장 경로에 진입 가능 | 재검수 전 저장 차단 | 차단 이유를 이해하는가? |
| 대조·수정 | B 자료를 확인해 본문 교정 | 확인할 곳이 많아 실수 가능 | 검토 상태를 계속 유지 | 대조에 얼마나 걸리는가? |
| 명시 검토 | 현재 자료와 내용이 일치하는지 확인 | 단순 편집을 승인과 혼동 가능 | 명시 검토 후 기존 승인 흐름 | 검토 확인의 의미를 이해하는가? |
| 저장·확인 | HWP 저장, 재열기 | 내용·서식이 변형될 위험 | 실제 저장·재열기 확인 | 파일을 다시 확인하는가? |

**가설 H1:** 재검수 안내가 명확하다면 사용자는 자료 변경 후 검토가 필요한 이유를 이해할 것이다. **미검증**.

**가설 H2:** 기존 본문을 보존하면 재작성 부담을 줄이면서도 잘못된 저장을 차단할 수 있을 것이다. 기능 보호는 합성 시험에서 검증했으나 실제 사용자 부담 감소는 **미측정**.

## 3. 향후 사용자 조사 설계 (미실행)

**대상 제안:** 결과서 작성 경험이 있는 실무자. 실제 모집 인원과 방법은 미정이다. 업무 원문·개인정보·기업 기밀을 요청하지 않으며 합성 자료로 관찰한다.

**인터뷰 질문 예시:** 최근 결과서를 작성한 순서, 가장 오래 걸린 단계, 자료 교체 빈도, 이전 내용 수정 과정, 잘못된 내용 제출 방지를 위한 현재 확인 방법, 날짜 입력 같은 반복적 불편. "이 기능이 좋았죠?" 같은 유도 질문을 피한다.

**관찰 과제:** A 초안 작성 → B 자료 변경 → 안내 확인 → B 내용 검토 → 검토 완료 → 안전한 저장. 진행자는 화면 이동·인지 여부·오류·과제 완료 여부를 기록하되 사용자를 대신해 조작하지 않는다.

**증거 저장 계획:** 합성 문서, 익명화된 관찰 표, 사용자 동의하에 수집한 시간·성공 여부만 보존. 개인/회사 원문과 API 키는 수집하지 않는다.
