# 검증 증거 — 공개용 집계

2026-11-12 기준. 보존된 원시 결과에서 비내용 집계를 옮겼으며 재측정한 값이 아니다. 원시 로그·실행 승인용 경로는 수정/삭제하지 않는다. 이 문서는 실제 시험 입력·실행 로그의 공개 승인을 대신하지 않는다.

| 증거 | 원시 기록 식별자 | 확인한 값 |
| --- | --- | --- |
| 개발 전 기준선 | C1-BL-v1 / v0.4.26-attempt-01 | 미검토 진입 18/18, 정상 오차단 0/30. C1 계약 18 실패·30 통과 |
| 개선 후 동일 시험 | C1-BL-v1 / candidate-final-01 | 미검토 0/18, 정상 오차단 0/30, 전체 48 통과, 인프라 오류·중복 호출·내용 불일치 0 |
| 신규 수용 | checks-final-01 | 25개 통과, 오류/실패/skip 0 |
| 기존 단위/GUI | regressions-final-01 | 151개 중 147 통과·4 skip, GUI QA 4/4 통과 |

16개 시나리오(U6/N10)를 3회씩 반복했다. 실제 Tk/App 조작·PDF 준비·승인 경계는 실행했고 API·HWP 준비/저장은 대역을 사용했다. 실제 HWP 생성·최종 재열기·C1 배포는 미완료다. AC01~AC13은 합성 통과, AC14는 모의 범위만 완료다.

제외한 4개는 실제 Windows 설치/바로가기 COM 검사다. 현재 HWP 파서 검사는 native 저장소 대역을 사용해 이전 151개 통과와 조건이 다르다. 중단 2회와 소스 변경 중 실행한 제외 회차도 보존하며 최종 합격 집계에 섞지 않았다.

초기 업무 3건 이상에서 평균 약 60분→3분·약95% 단축은 본인의 초기 적용 경험이며 건별 시간 원기록이 없다. C1 합성 결과와 합산하지 않는다. 활성 검수시간·운영 혼재율·만족도는 미측정이다.

기존 버전의 실제 API/한글 연동·배포·오류 이력은 기술 문서에 보존했다. 과거 시험의 배포 드라이브 경로는 당시 증거의 일부여서 변경하지 않았으며 여기서는 경로 대신 버전/시험 식별자로 설명한다. 과거 성공을 C1 실연동 성공으로 대체하지 않는다.
