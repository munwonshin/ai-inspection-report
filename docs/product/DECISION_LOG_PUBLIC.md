# PM 의사결정 기록 — 공개본

2026-11-12 기준. 실제 PM 지시와 검토 결과를 단계별로 요약했다. 원본 D-001 결정 기록·기준선·실패·내부 실행 승인안은 변경하지 않았다. 개인 이름·호스트 경로·자격증명은 포함하지 않는다.

## D-001: 첫 개선 과제로 C1 선정

**문제:** 자료를 바꾸면서 기존 본문을 보존하면 재검토 없이 다른 자료의 내용을 승인할 수 있었다. 기존 승인/복원 검사는 자료와 본문의 대응을 보장하지 않았다.

**선택:** C1 자료 변경 후 재검수를 먼저 개발하고 C3→C2 순으로 후속 검토한다. 영향도5·시급성4·개발 부담3, 가상 재현으로 확인한 최종 승인 공백, 1인 회귀 검증 가능성을 근거로 삼았다. 점수는 상대 판단이며 실제 발생률이 아니다.

| 보류 과제 | 보류 이유 | 재평가 조건 |
| --- | --- | --- |
| C3 수정 차이 확인 | 기존 복원이 있고 실제 손실 빈도는 미측정. C1과 본문/이력을 함께 바꾸므로 분리 | C1 상태 계약 검증 뒤 별도 요구 정의, 수정 손실·검수 부담 증거 |
| C2 저장 복구 | 영향은 크지만 장애 빈도·정상 시간 분포 미확인, COM·완료 불명·파일 보호 부담 큼 | 전용 환경·실제 반복 장애·프로세스 수명 확인 |

## 범위와 기준의 확정

- C1 MVP는 자료 식별·변경 표시·명시 검토·복원/비동기 일치·승인 전 보호의 다섯 범위다.
- 수동 작성·첨부 실패 보존·파일명/문서 제목 분리·복원·초기화·기존 승인 저장을 회귀 조건으로 둔다.
- AC01~AC14의 입력·동작·검증을 정의하고 X8 추가 분기를 따로 관리한다.
- 미검토 차단만 좋아지는 결과를 피하려고 M01 0/18과 M02 0/30을 동시에 목표로 고정한다.
- 파일명/폴더 변경은 검토를 유지하고, 내용/연도·분과 변경은 무효화한다. 줄바꿈 형식만 정규화하고 공백·숫자 변경은 재검수한다.
- 자동 사실 판정·수정 diff·timeout/복구는 추가하지 않는다. 범위를 넓히는 대신 기존 상태·정상 흐름 보존을 검증한다.

## 실제 후속 의사결정

| 단계 | 근거/불확실성 | 실제 결정 | 결과·상태 |
| --- | --- | --- | --- |
| 기준선 요청 | 두 가상 재현만으로는 고정 분모의 개선 비교 불가 | 개인정보 없는 합성 자료·16시나리오×3회로 측정 | 미검토18/18·정상 오차단0/30, baseline 실패를 보존 |
| 조건부 개발 승인 | 보호 공백 재현, 요구·KPI 확정 | 별도 feature 브랜치에서 C1만 구현. 원본 보호 완화 금지 | 로컬 구현 완료. 기능 main 병합/릴리스 없음 |
| fixture 정비 | 기존 workflow QA의 필수 연도·분과 누락 | 별도 커밋으로 fixture 보완, 보호 로직 완화 금지 | GUI QA4/4, 이전 실패 기록 유지 |
| 결과 검토 | 같은48회 통과·신규25 통과·기존147+설치COM4 제외 | 합성 검증 결과를 조건부 승인 | 실제 저장 함수 진입과 HWP 생성 결과를 구분 |
| 실연동 검토 | AC14 모의만 완료, 기존 한글 세션 격리·정지 대응 미검증 | 실제 COM은 전용 환경 준비 전 보류 | 실제 HWP 생성/재열기·배포 미완료 |
| 공개 범위 결정 | PM 설명은 필요하나 원시 기록·내부 경로는 공개 최소화 | 문서·합성 실제 화면만 main에 게시 | 프로그램 소스·원시 증거·기존 이력 변경 없음 |

초기에는 분석·명세만 허용했고 기준선 측정, 조건부 개발, 합성 결과 승인으로 단계적으로 진행했다. 완료한 범위를 넓게 소급해 기록하지 않는다. 분석 초기의 C1→C2→C3 제안은 우선순위 재검토 뒤 C1→C3→C2로 변경했다. 구현 단계에서는 C2/C3을 추가하지 않았다.

## 출시 판단

합성 시도18회를 모두 차단하고 정상30회를 허용해도 최종 HWP 내용/서식과 다른 한글 세션 보호가 보장되지는 않는다. 따라서 **C1 로컬 구현·합성 결과는 승인, 정식 출시·기능 main 병합은 보류**했다. 실제 프로그램/기존 배포본은 v0.4.26이며 C1 실제 API·COM 시험과 실사용 검수시간은 완료됐다고 표현하지 않는다.

전용 환경과 별도 실행 승인 후 실제 저장·재열기·내용/서식·기존 파일 보호·회귀·배포 환경을 확인해 재판단한다. 캡처와 문서 공개는 제품 출시 승인이 아니다. 실제 장애 증거가 생기면 후속 순위도 재평가한다.
