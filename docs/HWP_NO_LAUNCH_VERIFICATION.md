# HWP 직접 읽기와 첨부 시 한글 자동 실행 제거 — 0.4.20

## 변경 내용

HWP 첨부는 `documents.prepare_hwp → hwp_direct.prepare` 경로로 처리합니다. 한글 애플리케이션을 실행하거나 전체 PDF로 자동 변환하지 않습니다. 이전 입력 변환 worker의 main.py 진입점을 제거했습니다. 사용자가 승인한 결과를 HWP로 저장하는 엔진은 유지합니다.

HWP 5의 전체 본문·표·셀 병합·참조 그림·배경 그림·수식 원문을 메모리에서 읽습니다. 지원 래스터 그림은 이미지 입력으로 전달하고 SVG는 로컬 PNG로 렌더링합니다. 문서의 스크립트·지시문은 실행하지 않으며 외부 그림·리소스를 자동으로 따라가지 않습니다.

미지원 개체나 손상·보호 문서는 안내하고 기존 첨부·회의록·편집 초안을 유지합니다. 원본 페이지를 시각적으로 재현하는 도구가 아니므로 근거 위치는 실제 쪽수 대신 HWP 구역 번호로 구분합니다.

## 코드에 정의된 지원 범위

- 입력 HWP 5 한 개, 최대 30MB·250구역·추출 텍스트 45만 자
- PNG/JPEG/BMP/GIF/TIFF/WebP 및 안전하게 해석 가능한 SVG
- 서로 다른 그림 최대 256개, 그림당 8MB, 전체 이미지 입력 크기 제한
- 다중 프레임·미지원 도형·OLE·외부 연결·보호 문서는 명시적으로 거부
- .hwpx는 미지원. 필요한 경우 사용자가 PDF 사본을 직접 첨부

이 값은 구현된 입력 제한이며 특정 업무 문서의 측정 결과가 아닙니다.

[가상 자료 실제 AI 검사 도구](../qa/direct_visual_workflow.py)는 Windows·한글·유효한 API 설정이 필요하며 API 비용이 발생합니다. 저장된 키는 출력하지 않습니다. 단위검사는 API 호출 없이 실행합니다.

## 검증 한계

모든 HWP 형식·페이지 배치·그림 효과의 정확한 재현을 보장하지 않습니다. 다른 PC·한글 버전·실제 NAS와 전체 업무시간은 별도 검증이 필요합니다. 출력은 저장 엔진의 재입력 내용 검사를 확인했으며 이번 변경에서 전체 페이지의 별도 육안 검수를 수행한 것으로 표시하지 않습니다.

실제 사업계획서·회의록·결과서, 업무자료에서 파생된 비공개 구조/성능 수치, 로컬 진단 산출물과 API 키는 이 공개 기록에 포함하지 않습니다.
