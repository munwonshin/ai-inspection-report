# 0.4.11 오늘 날짜 파란 표시

앱 내부 달력에서 PC의 현재 날짜를 파란 배경(#2563EB)과 흰 숫자로 표시한다. 방문일자로 선택한 날짜와 별개로 오늘을 강조하며, 현재 표시한 달에 오늘이 없으면 다른 날짜를 잘못 강조하지 않는다. 기존 ‘오늘’ 버튼은 현재 날짜를 방문일자로 바로 입력하는 기능을 유지한다.

열 때마다 현재 날짜를 확인한다. 열려 있는 동안에는 1초 간격으로 PC 날짜를 확인하여 날짜 변경 시 강조만 갱신한다. 방문일자 입력값·표시 중인 달·키보드 포커스는 자동 변경하지 않는다. 달력을 닫거나 부모 창이 닫히면 이 타이머를 정리한다. 날짜 표시에는 API 호출·외부 전송이 필요하지 않다.

## 실제 검증 (2026-10-23)

가상 시계와 실제 Tk 이벤트 루프 타이머로 23→24일 강조 이동을 확인했다. 기존 방문일자 유지, 다른 달의 같은 숫자 미강조, 월말 10/31→11/1과 연말 12/31→1/1, 다시 열기·오늘 선택·처리 중 닫기와 타이머 해제도 통과했다. 실제 자정까지 대기한 검사가 아니라 가상 시계 날짜를 바꾼 검사다. 스타일 값이 파랑/흰색임을 확인했으며 화면 캡처 육안 검수는 미실시다.

앱 내부 달력의 별도 창 없음/채팅 입력 위 위치/6주 달/한 번 클릭 선택을 기본·큰 글꼴 및 두 창 크기의 네 조합에서 재검증했다. 달력·고정값 7개 시나리오, Windows 고정 체크 표시·키보드·재실행 복원, 전체 단위 67개도 통과했다.

최종 EXE의 12개 모듈 소스 일치와 TkDND/TLS 로딩, AI/HWP/보안 저장소 등 변경하지 않은 모듈의 직전 버전 바이트 일치를 배포 전에 검사한다. 이번 변경은 실제 API·실물 NAS·한글 재열기 검사를 추가 수행하지 않는다. 기존 결과는 버전별 기록과 구분하며 시간 단축 목표를 실측 성과로 주장하지 않는다.
