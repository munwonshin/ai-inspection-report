# 0.4.17 출력 머리글·문서 제목 검증

검증일: 2026-11-02. Windows 11·한글 2018. 제공 이미지는 배치 비교에만 참고했고 실제 기업명·과제·본문을 재사용하지 않았습니다.

## 변경

- 출력 문서의 ‘별첨2 / 현장점검결과서’ 머리글 표와 해당 문단을 제거합니다. 원본 양식 파일은 수정하지 않습니다.
- 회색 제목 칸에는 저장 파일명 대신 사업계획서의 사업연도·분과를 사용한 표준 제목을 넣습니다. 예: 2026년 AI바우처 현장점검 결과 (일반분과).
- 일반·반도체·소상공인·글로벌 분과를 지원합니다. 사업연도·분과는 일반현황에서 확인·수정할 수 있으며 미확인·잘못된 값은 저장 전에 보완해야 합니다. 시스템 현재 연도나 파일명에서 추측하지 않습니다.
- 하단 입력란은 ‘저장 파일명’으로 구분했습니다. 문서 제목은 불변 승인 스냅샷의 별도 필드로 전달하여 직접 지정한 파일명과 분리합니다.
- 기존 일반현황·본문·방문/점검자 표, 본문 10pt·문장 사이 빈 문단 고정 3pt, 승인 전 저장 차단·덮어쓰기 방지는 유지합니다.

## 검증 결과

- 단위검사 103개 통과(기존 98개 + 출력 머리글·제목 5개). 머리글 제거, 문서 제목/파일명 분리, 네 분과·다른 사업연도, 미확인 값 거부, 머리글/제목 변조 탐지 등을 확인했습니다.
- 실제 Tk에서 사업연도·분과 수정, 누락값 저장 차단, 파일명 보존, 첨부 교체 시 문서 정보 초기화, 인식 결과가 제목으로 연결되는 것을 확인했습니다. 저장 후 연도·분과 수정 시 이전 저장 상태와 파일 열기 버튼이 해제되는 것도 확인했습니다. 이 컨트롤러 회귀의 API는 모의 처리했습니다.
- 가상 자료를 실제 앱과 동일한 독립 한글 작업으로 네 번 저장했습니다. 일반·반도체·소상공인·글로벌 모두 표준 제목과 다른 파일명으로 진짜 HWP 저장 및 한글 재입력 검증을 통과했습니다. 이 짧은 가상 본문 결과는 각 1쪽입니다.
- 긴 가상 본문은 2쪽으로 저장·재열었고 일반분과 PDF를 렌더링해 첫 페이지가 회색 제목 칸부터 시작하며 별첨 머리글과 파일명 본문이 없는 것을 확인했습니다. 본문 10pt·3pt 빈 문단·일반현황·방문/점검자 표도 유지됐습니다.
- 동일 한글 인스턴스의 추가 분과 PDF 내보내기는 지연되어 중단했습니다. 네 분과의 최종 검증은 실제 제품처럼 독립 저장 작업으로 수행했으며, PDF 시각 검수는 일반분과에 한정합니다.
- 최종 EXE의 16개 모듈이 소스와 일치했습니다. EXE에서 소상공인분과 제목과 다른 파일명을 지정해 진짜 HWP 저장·재입력 검증을 통과했습니다(1쪽).
- 원본 template.hml 해시는 변경되지 않았습니다. 이번 변경 시험에서는 실제 업무자료와 API 키를 배포·소스에 포함하지 않았고 새 AI 요청을 수행하지 않았습니다.

관련 검사: tests/test_report_header.py, qa/report_header_checks.py, qa/report_header_roundtrip.py. 다른 PC·한글 버전·실제 NAS는 이번에 추가 검증하지 않았습니다.
