# 가상 모델 비교 자료

`synthetic_results.json`은 실제 비교 96요청의 응답 전문·usage와 원래 자동판정 및 별도 검토 의견이다. `token_cost.csv`는 토큰·추정 비용 비교다. 실제 기업 자료는 포함하지 않는다. 실패 결과도 삭제하지 않았다.

재실행은 별도 유료 API 시험이며 앱의 정상 사용에 필요하지 않다. 앱 의존성과 추가로 reportlab·Pillow가 필요하다. Windows 맑은 고딕 글꼴을 사용한다.

1. `python make_fixtures.py`로 명확한 가상 PDF 3개를 만든다.
2. 앱에서 현재 Windows 사용자 보안 저장소에 키를 저장한다. 키를 파일에 넣지 않는다.
3. `python run.py --allow-api`로 최종 방식 5모델 × 3자료 × 2반복 × 2단계, 총 60요청을 실행한다. 결과는 이 시험 폴더의 benchmark_final.json에 기록된다. 이 기록은 시험용이며 앱이 업무내용을 로그로 남기는 기능이 아니다.

과거 0.1 비교를 위한 `baseline_api.py`도 포함한다. 초기 36요청의 개선 중간 지시문과 최종 60요청의 지시문은 서로 다르므로 비교 보고서의 조건을 확인한다. 초기 결과는 선정의 최종 통과율에 합산하지 않는다.

자동판정은 표현 차이로 오판할 수 있다. API 반환 토큰과 응답 전문을 함께 확인하고 근거 구분·누락·직접 편집 보존을 검수해야 한다. 재실행 시 캐시·서버 모델·통신 상태·생성 결과가 달라질 수 있다.
